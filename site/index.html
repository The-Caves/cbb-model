THE METHOD

Built on evidence

This project uses open data, a reproducible Python model, and date-aware evaluation. It's intentionally transparent about what's available and what's not.

01

Opponent-adjusted scores

The featured v0.5 experiment blends 20% of a 512-draw, opponent-informed possession/shot simulator with 80% of the lighter-carryover score model. Original v0.4 forecasts remain preserved as fallback.

02

Pregame-only freezing

Only actually captured pre-tip forecasts are displayed. The interim v0.5 blend is used where its frozen record is valid; otherwise the original v0.4-era forecast is shown, with version attribution preserved.

03

Walk-forward tests

Historical evaluation simulates each day using only prior completed game scores. Captured historical data was collected retrospectively, so those tests are kept separate from live accuracy.

04

Open data, no bills

Public scoreboards, standard Python dependencies, GitHub Actions, and GitHub Pages. No paid sportsbook APIs, servers, or premium runners.
